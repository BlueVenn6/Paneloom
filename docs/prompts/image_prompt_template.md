# Manga Panel Image Prompt Template

Use this pattern for one generated panel:

```text
Manga storyboard panel, {visual_style}, {character_and_action},
{location}, {camera_composition}, expressive face and body language,
clean line art, clear silhouettes, no text in image
```

Default negative prompt:

```text
watermark, random text, speech bubble text, logo, distorted hands,
bad anatomy, duplicated character, low quality
```

For narrated-comic workflows, keep speech and narration in `revision_notes`.
Add text later in editing software or a dedicated lettering step.
