# Paneloom icon assets

`paneloom-icon-source.png` is AI-generated artwork supplied by the Paneloom
project owner. On 2026-07-18, the project owner confirmed that they hold the
necessary usage rights and authorize the artwork to be redistributed as part
of Paneloom under the project's MIT License.

`paneloom-icon.png`, `paneloom.ico`, and the matching frontend public asset are
derived from that source. The derivation only crops transparent padding,
centers the globe on a transparent square canvas, and creates standard Windows
icon sizes. It does not add a background plate, outer border, rounded square,
or shadow.
