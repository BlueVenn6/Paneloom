# Code of conduct

Paneloom contributors must keep project spaces respectful, constructive, and
free from harassment. Disagreement about product or engineering decisions is
welcome when it focuses on evidence and the work rather than individuals.

Unacceptable behavior includes harassment, threats, discriminatory language,
publishing another person's private information, sharing project files or API
credentials without permission, and sustained disruption of project work.

This policy applies to issues, pull requests, discussions, reviews, and private
project communications. Maintainers may edit or remove inappropriate content,
close participation, or ban contributors when necessary.

Report conduct issues privately through the repository owner's profile. Do not
publish sensitive evidence in a public issue. Reports will be reviewed for
context, impact, and a proportionate response.

This policy is informed by the Contributor Covenant 2.1.
